# بوت Discord لإرسال GIF

بوت بسيط: كل ما حدا يبعت رسالة بشات محدد، البوت بيرد بصورة GIF — الصورة نفسها موجودة جوا مجلد `gifs/` بالمشروع، ما في حاجة لأي رابط خارجي أو رفع على مواقع صور.

## 1) إنشاء البوت على Discord

1. روح على https://discord.com/developers/applications واعمل **New Application**.
2. من تبويب **Bot** اعمل **Add Bot**.
3. فعّل خيار **MESSAGE CONTENT INTENT** (تحت Privileged Gateway Intents) — ضروري وإلا البوت ما رح يشوف الرسائل.
4. انسخ الـ **Token**.
5. من **OAuth2 > URL Generator**: اختار scope `bot` فقط (بدون `identify` أو `applications.commands`)، وصلاحيات `View Channels`, `Send Messages`, `Attach Files`. افتح الرابط اللي بيتولد وضيف البوت عالسيرفر.

## 2) معرفة أرقام (IDs) الشاتات

1. فعّل **وضع المطور** (Settings > Advanced > Developer Mode).
2. كليك يمين على أي شات > **Copy Channel ID**.

## 3) إضافة ملفات الـ GIF

- حط كل ملفات الـ GIF (أو صور PNG/JPG لو حبيت) جوا مجلد `gifs/` بنفس مكان `bot.py`.
- البوت بيختار وحدة عشوائياً كل مرة يرسل فيها.
- **مهم:** خلي حجم كل ملف صغير قد الإمكان (تحت 8 ميجا مثالياً) وإلا الرفع على Discord ممكن يفشل. لو الملف كبير، صغّره أول بموقع مثل ezgif.com/optimize (استخدم أداة **Resize** لتصغير الأبعاد الفعلية، مش بس **Optimize**).

## 4) الرفع على Railway

1. ارفع كل مجلد المشروع (بما فيه مجلد `gifs/` وملفاته) على GitHub.
2. اربط الـ repo بمشروع جديد على Railway.
3. من تبويب **Variables**، ضيف بس:
   - `DISCORD_TOKEN` = التوكن تبع البوت
   - `ALLOWED_CHANNEL_IDS` = أرقام الشاتات مفصولة بفاصلة (اختياري، لو تركتها فاضية البوت بيرد بكل مكان)
4. Railway بيقرأ `Procfile` تلقائياً ويشغل البوت كـ **Worker**. تأكد إنو نوع الخدمة (Service Type) هو Worker مش Web.

## ملاحظات

- ما في حاجة لأي رابط GIF أو متغير `GIF_URLS` — كل شي بقى محلي جوا المشروع.
- لو بدك تغيّر الصورة أو تضيف وحدة جديدة، بس ارفع الملف الجديد على GitHub جوا مجلد `gifs/` واعمل Commit — Railway بيعيد الـ deploy تلقائي.
- البوت بيتجاهل رسايل البوتات الثانية (وبضمنها حاله) عشان ما يصير تكرار لانهائي.
